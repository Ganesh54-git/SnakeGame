# 🐍 Snake Game (Python + Pygame)

A simple yet fun implementation of the classic Snake game using Python and Pygame.

## 🎮 Features

- Smooth keyboard controls (Arrow keys)
- Real-time score display
- Random food generation
- Game over and restart options
- Clean UI with color-coded visuals

## 🚀 How to Run

1. **Install Python** (if not installed): [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. **Install Pygame**:
   ```bash
   pip install pygame
